# Circle packing: manuscripts and sources

Manuscripts and source links for the film *Why These Circles Cannot Fit Any Tighter*, which follows the ideas behind proposed optimality proofs for packing 15, 16, 17, 18 and 20 equal circles in a circle.

**Status.** The manuscripts are working drafts from October 2026. Independent mathematical review is pending. Nothing here should be cited as an established result.

The TeX files are the authors' archived sources, unchanged. The fifteen-circle PDF was compiled from that TeX for the film; the four-case PDF is the archived one. The four-case TeX keeps its older file name although it covers 16, 17, 18 and 20.

## Archive records

`records/` holds the development notes the film cites (S3 to S13 in the register): the failed shadow inequality and its numerical test, proof plans, search histories, local arguments, the twenty-circle status file, construction coordinates, a build receipt and the hub entry. They are saved as written, including approaches that were abandoned.
